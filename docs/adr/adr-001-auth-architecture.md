# ADR-001: 인증 아키텍처 결정

## 상태
승인됨 (2024-03)

## 배경
기존 세션 기반 인증 구조는 다음 문제를 가지고 있었다.
- 서버 확장 시 세션 공유 필요
- API Gateway와의 연동 복잡성

## 고려한 대안
1. 세션 기반 인증 유지
2. JWT 기반 인증
3. OAuth 기반 인증

## 결정
JWT 기반 인증 방식을 채택한다.

## 이유
- Stateless 구조로 수평 확장 용이
- 마이크로서비스 간 인증 정보 전달 용이

## 결과 및 영향
- Access Token 만료 정책 필요
- 토큰 탈취 시 보안 리스크 증가
- 클라이언트 토큰 관리 책임 증가

## 추가 논의 사항
Refresh Token 도입 여부는 추후 검토한다.
보안 강화 방안은 별도 문서에서 다룬다.
